### 1. Какие данные нам нужны

У нас схема:

```text
users
  │
  └── projects
         │
         └── tasks
```

Поэтому сначала создаём пользователей, затем проекты с их `user_id`, затем задачи с `user_id` и `project_id`.

Например, можно взять проекты и задачи из учебного массива:

```text
Пользователи:
Иван
Анна

Проекты:
Входящие
Учёба
Работа
Домашние дела
Авто

Задачи:
Пройти собеседование
Сходить на встречу с другом
Покормить кота
Купить пиццу
```

Но здесь есть важный момент: **в задании сказано "существующий список проектов" и "существующий список задач"**. Если в твоём проекте уже есть конкретные массивы `$projects` и `$tasks`, лучше использовать именно их, а не придумывать свои.

Если пришлёшь/покажешь эти массивы из `index.php`, я составлю `queries.sql` **точно под данные проекта**, чтобы потом всё совпадало с PHP-кодом.

### 1. Сначала пользователи

```sql
INSERT INTO users (name, email, password)
VALUES
  ('Рамиль', 'ramil@example.com', 'password_hash_1'),
  ('Анна', 'anna@example.com', 'password_hash_2');
```

Пока для учебного SQL можно поставить условные строки вместо настоящего хеша. В реальном PHP пароль должен сохраняться через `password_hash()`, как требует ТЗ.

После вставки допустим получаем:

```text
users

id | name   | email
---+--------+-------------------
1  | Рамиль | ramil@example.com
2  | Анна   | anna@example.com
```

### 2. Проекты

Все пять проектов из массива принадлежат Рамилю:

```sql
INSERT INTO projects (name, user_id)
VALUES
  ('Входящие', 1),
  ('Учеба', 1),
  ('Работа', 1),
  ('Домашние дела', 1),
  ('Авто', 1);
```

Здесь `user_id = 1` — это связь проекта с Рамилем.

Получится примерно:

```text
projects

id | name           | user_id
---+----------------+--------
1  | Входящие       | 1
2  | Учеба          | 1
3  | Работа         | 1
4  | Домашние дела  | 1
5  | Авто           | 1
```

### 3. Задачи

Теперь самое интересное — нужно одновременно указать **пользователя и проект**.

```sql
INSERT INTO tasks
  (name, deadline, status, user_id, project_id)
VALUES
  ('Собеседование в IT-компании', '2019-12-01', 0, 1, 3),
  ('Выполнить тестовое задание', '2026-09-04', 0, 1, 3),
  ('Сделать задание первого раздела', '2019-12-21', 1, 1, 2),
  ('Встреча с другом', '2019-12-22', 0, 1, 1),
  ('Купить корм для кота', NULL, 0, 1, 4),
  ('Заказать пиццу', NULL, 0, 1, 4);
```

Обрати внимание на соответствие:

```text
'Собеседование...'       → Работа       → project_id = 3
'Выполнить тестовое...'  → Работа       → project_id = 3

'Сделать задание...'     → Учеба        → project_id = 2

'Встреча с другом'       → Входящие     → project_id = 1

'Купить корм...'         → Домашние дела → project_id = 4
'Заказать пиццу'         → Домашние дела → project_id = 4
```

А `status` берём непосредственно из `completed`:

```text
completed: false → status = 0
completed: true  → status = 1
```

И даты из `data.php` переводим из PHP-вида:

```text
01.12.2019
```

в SQL-вид:

```text
2019-12-01
```

## 4. Запросы из задания

Теперь ниже `INSERT` пишем четыре запроса.

### Получить все проекты одного пользователя

```sql
-- Получить список всех проектов для одного пользователя
SELECT name
FROM projects
WHERE user_id = 1;
```

### Получить все задачи одного проекта

```sql
-- Получить список всех задач для одного проекта
SELECT name
FROM tasks
WHERE project_id = 3;
```

### Пометить задачу как выполненную

```sql
-- Пометить задачу как выполненную
UPDATE tasks
SET status = 1
WHERE id = 2;
```

### Обновить название задачи по идентификатору

```sql
-- Обновить название задачи
UPDATE tasks
SET name = 'Выполнить тестовое задание для компании'
WHERE id = 2;
```

### Как смотреть

Да, конечно. И **в PhpStorm это даже удобнее**, потому что мы уже подключили базу через Database Tool.

В правой панели **Database** раскрой:

```text
DoingsDone
└── doingsdone
    └── Tables
        ├── projects
        ├── tasks
        └── users
```

Если `Tables` не видно — нажми **Refresh** (иконка обновления) на панели Database.

### Посмотреть содержимое таблицы

Раскрой, например:

```text
Tables
└── users
```

Нажми **правой кнопкой по `users` → `Jump to Data`** / **Edit Data** (название может немного отличаться).

PhpStorm покажет таблицу примерно так:

|  id | registration_date | email | name | password |
| --: | ----------------- | ----- | ---- | -------- |
| ... | ...               | ...   | ...  | ...      |

То же самое можно сделать для `projects` и `tasks`.

### А посмотреть структуру таблицы

У таблицы раскрой:

```text
users
├── Columns
├── Keys
├── Foreign Keys
└── ...
```

Там можно увидеть, например:

```text
projects
├── id
├── name
└── user_id
```

и `user_id` будет внешним ключом на `users.id`.

### Есть ещё очень удобный вариант

Можно просто открыть **Query Console** и выполнить:

```sql
SELECT * FROM users;
SELECT * FROM projects;
SELECT * FROM tasks;
```

А если хочешь посмотреть именно структуру:

```sql
DESCRIBE users;
DESCRIBE projects;
DESCRIBE tasks;
```

Для обучения я бы использовал **оба способа**: дерево Database — чтобы видеть структуру БД как целое, а `SELECT` — чтобы привыкать работать с базой через SQL.
